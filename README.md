# Java Quiz Challenge 🎯

A simple **console-based quiz game** written in Java. This project is designed for beginners who are learning Java fundamentals such as arrays, loops, conditional statements, and user input.

## ✨ Features

- 📚 5 General Knowledge Questions
- 📝 Multiple Choice (A, B, C, D)
- ✅ Checks correct and incorrect answers
- ❌ Validates invalid user input
- 🏆 Displays final score
- 💻 Runs entirely in the terminal

## 🛠️ Technologies Used

- Java
- Scanner Class
- Arrays
- 2D Arrays
- Loops
- Conditional Statements

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/Java-Quiz-Challenge.git
```

2. Open the project in your favorite Java IDE (VS Code, IntelliJ IDEA, Eclipse, etc.).

3. Compile the program

```bash
javac Main.java
```

4. Run the program

```bash
java Main
```
